**Agent Skills** let coding agents do real work on your Semantius platform: build modules, evolve schemas, set up roles and permissions, import data, and move modules between hosts. They install into any agent that supports the Agent Skills format.

## What Skills Do

Each skill is a structured, repeatable procedure an agent can invoke:

- **[use-semantius](/docs/agent-skills/use-semantius)**: build a module from a description, review or change an existing one, set up roles and permissions, work with records, and answer analytical questions.
- **semantius-importer**: import a CSV file. It maps the columns to field formats, creates the entity or adds to an existing one, and loads the rows.
- **semantius-transfer**: copy modules and tables, with or without their records, to another host or into a file you can restore.

Skills give agents a vocabulary and a workflow, instead of leaving them to improvise. They work on your instance directly, and follow the [Conventions](/docs/conventions).

## Installation

[Install the Semantius CLI and skills](/docs/agent-skills/installation) into your agent of choice. The skills are agent-agnostic: anything that supports Agent Skills can use them.

Among the agents we test against:

- **OpenClaw**
- **Claude Code**

If your agent supports Agent Skills, it works.

The skills also call into your platform's [MCP connectors](/docs/mcp-connectors) under the hood, so make sure those are wired up too.

## Ready-to-Use Models

Skills are also how ready-to-use models are installed and customized. You can pull a published template into your platform, fork it, and let the skills handle the migration steps so the underlying data stays consistent.
