Reference documentation for every part of Semantius. Start with the
[Overview](/docs/reference/overview) if you are new, or jump straight to the
area you are working in.

## Overview

[What Semantius is](/docs/reference/overview) and how semantic models, MCP
servers, agent skills and the CLI fit together.

## Models

[Models](/docs/reference/models) are the centre of Semantius. Learn how a model
is [structured](/docs/reference/models/structure), how to
[create](/docs/reference/models/create) one, how to start from a
[template](/docs/reference/models/templates), and how to
[deploy](/docs/reference/models/deploy) and
[optimize](/docs/reference/models/optimize) it.

## Business Logic

[Business logic](/docs/reference/business-logic) is expressed in
[JsonLogic](/docs/reference/business-logic/jsonlogic), plus the
[extensions](/docs/reference/business-logic/extensions) Semantius adds for
record-level computed fields, validation rules and permissions.

## MCP Connectors

[MCP connectors](/docs/reference/mcp-connectors) expose your model to AI chats.
See [installation](/docs/reference/mcp-connectors/installation) to connect one.

## Agent Skills

[Agent skills](/docs/reference/agent-skills) give coding agents domain
expertise for your model. See
[installation](/docs/reference/agent-skills/installation) to add them.

## CLI

The [CLI](/docs/reference/cli) drives Semantius from your terminal: the
[semantius command](/docs/reference/cli/command) and the
[use-semantius skill](/docs/reference/cli/use-semantius).
