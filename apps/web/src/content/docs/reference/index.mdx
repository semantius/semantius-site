Reference documentation for every part of Semantius. Start with the
[Overview](/docs/overview) if you are new, or jump straight to the
area you are working in.

## Overview

[What Semantius is](/docs/overview) and how semantic models, MCP
servers, agent skills and the CLI fit together.

## Models

[Models](/docs/models) are the center of Semantius. Learn how a model
is [structured](/docs/models/structure), how to
[create](/docs/models/create) one, how to start from a
[template](/docs/models/templates), and how to
[deploy](/docs/models/deploy) and
[optimize](/docs/models/optimize) it.

## Business Logic

[Business logic](/docs/business-logic) is expressed in
[JsonLogic](/docs/business-logic/jsonlogic), plus the
[extensions](/docs/business-logic/extensions) Semantius adds for
record-level computed fields, validation rules and permissions.

## MCP Connectors

[MCP connectors](/docs/mcp-connectors) expose your model to AI chats.
See [installation](/docs/mcp-connectors/installation) to connect one.

## Agent Skills

[Agent skills](/docs/agent-skills) give coding agents domain
expertise for your model. See
[installation](/docs/agent-skills/installation) to add them.

## CLI

The [CLI](/docs/cli) drives Semantius from your terminal: the
[semantius command](/docs/cli/command) and the
[use-semantius skill](/docs/cli/use-semantius).
