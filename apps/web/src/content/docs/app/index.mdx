The Semantius app is a responsive web app. It provides traditional
access to the data platform, beyond the agent-optimized
[skills](/docs/agent-skills) and [CLI](/docs/cli).

You can host the app yourself to brand and customize it completely.
A self-hosted app works with both
[Semantius Cloud](https://app.semantius.com) and a
[self-hosted](/docs/self-hosted) Semantius backend. Its source is in
the [semantius-app](https://github.com/semantius/semantius-app)
repository.
